# Welcome

## Overview
This webpage made for my portfolio. I deployed it in github pages using domain alias [odorifqi.dev](https://odorifqi.dev/)

## How to Develop
1. Run `npm install`
2. Run `npm start`
3. Run `npx tailwindcss -i ./src/input.css -o ./src/output.css --watch`
4. Add code and make sure the tailwind output is updated.
5. After all good, run `npm run build`
6. Push the change.
